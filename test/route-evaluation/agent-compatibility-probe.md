# Dify Agent 兼容性探测：C01

探测时间：2026-10-24（本地 Dify Agent `城市旅行规划 Agent`）。

## 输入

测试集 C01：上海人民广场出发，13:30 开始，仅 3 小时；偏好独立书店和本地小吃，排除连锁店并要求少走路。

Agent 的表单设置填入了 `raw_input`、`destination=上海`、`days=1`；对话中补充了“上海，独自旅行”及上述完整条件。

## 实际输出

Agent 返回标题为“上海 2 天行程方案（3 套可选）”。每套方案均包含 Day 1 和 Day 2，单日标记为 3.0 小时。输出中未给出独立书店；地点包括上海展览中心、外滩、豫园、南京路步行街、龙华寺和上海交通大学闵行校区等。

## 评测结论

该输出不能与 TripBeam 的单日 30–240 分钟、出发点 8km 范围路线进行公平比较，原因是：

- 固定生成两天，违反 C01 的 3 小时总时长；
- 未遵守“独立书店”这一关键自由偏好；
- 输出的时间、步行距离和费用均未由 TripBeam 地图服务核验；
- Agent 的表单 `days=1` 未反映在最终“2 天”结果中。

在 Agent 支持单日短时约束前，不应批量执行其余 19 条作为路线质量对比；这些结果可以用于评估通用多日行程文案，但不能作为 TripBeam 方案替换的依据。

## 继续对比前的最低改造要求

1. 工作流输入增加并实际使用 `origin`、`startTime`、`availableMinutes`、`playPreferences`、`customPreferences` 与 `travelPreferences`。
2. 当 `availableMinutes` 存在时，只返回一个单日方案，且累计安排不超过该分钟数。
3. 输出结构化地点候选、顺序和体验理由；时间、距离、费用与可行性不作为可信结论。
4. 每个方案显式回显被满足的自由偏好，便于自动检查“独立书店”等条件是否被遗漏。
