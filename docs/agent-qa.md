## 浏览器流程

| 场景 | 验收结果 |
| --- | --- |
| 新用户进入首页 | 未发请求前显示旅行助手身份，不声称已经建立会话 |
| 中文输入法选词时按 Enter | 不提交对话，不创建会话 |
| 手动补全五项条件 | 出发点、时间、时长、兴趣、交通逐步确认后生成至少两条方案 |
| 返回首页并刷新 | 恢复同一个会话、已确认偏好及继续查看方案入口 |
| 点击解释路线 | 返回解释与处理记录，不新增行程，不跳转到另一方案 |
| 自然语言「删掉第二站」 | 删除指定节点、重新计算路线、更新列表 |
| 添加地点导致时间超限 | 显示拟修改草稿、超限原因，保留原有效路线；保存禁用 |
| 放弃未通过草稿 | 恢复有效路线，可以继续保存 |
| 保存并创建分享 | 成功打开固定快照的分享页 |
| 剪贴板被拒绝 | 展示可手动复制的完整行程内容 |
| 四个页面桌面与手机视口 | 均未发生页面横向溢出 |

新增会话 helper 单测还验证并发初始化去重、服务端恢复、过期会话替换、短暂网络失败时保留缓存，以及每轮结果持久化。后端新增测试覆盖中文数字/时间解析、表单覆盖偏好、多轮失败恢复、解释与生成边界、编辑草稿恢复等。

浏览器测试曾因编辑页 URL 匹配使用单层通配符而超时；应用实际已正常跳转。脚本已改为匹配两段 ID，并完整重跑通过。此失败属于验收脚本问题。脚本现在无论通过或失败，都会写入结果 JSON；失败还会保留错误堆栈、当前 URL 与截图。

截图检查发现手机地图降级提示与底部按钮重叠，已调整提示和按钮间距；修复后再次完整执行浏览器脚本，16 项仍全部通过，并更新了全部截图。

## 尚未验证和后续范围

- 本轮未运行真实高德、DeepSeek/Dify、生产 PostgreSQL 或真实地图瓦片联调；离线测试不能证明真实地点质量、模型表现、外部配额与网络可用性。
- 未重现参考介绍中的「10 组案例、30 条路线」及冷/热启动延迟数据，不应把这些数字当作本轮测试结果。
- 预算、排队时长、实时营业、预约、实时交通、天气以及多日行程仍不属于当前已验证能力；产品当前定位为 30 分钟至 4 小时的城市短途规划。
- 当前 UI 在单页内防止并发编辑；跨标签页/多实例的会话轮次串行化和数据库会话版本控制仍需后续专项验证。
- 账户权限、公开多用户访问隔离、生产监控和限流策略仍需上线前专项检查。现有匿名会话不能替代完整用户鉴权。
- 已检查桌面与 390px 视口的闭环和布局；未覆盖全部浏览器、真实移动设备、屏幕阅读器或弱网组合。
